# locum architecture & module contracts

This file is the **source of truth for cross-module APIs**. Every module must
implement exactly the public names/signatures listed for it, so modules written
independently fit together. Adding extra helpers is fine; renaming is not.

Package root: `src/locum/`. Python >= 3.9 (use `from __future__ import annotations`,
`typing.Optional/List/...`, no `match`, no PEP 604 unions at runtime).
Hard deps: `pillow`, `numpy`, `mss` (+ `python-xlib` on Linux, `comtypes` on Windows,
`pyobjc` on macOS). Everything else is optional and imported lazily inside functions
(raise `NotSupported`/`ImportError` with an install hint like `pip install locum[llm]`).
**Importing any module must work on every OS with only hard deps installed**
(platform imports go inside functions / try-blocks).

## Layering

```
cli.py ─────────────────────────────────────────────────────────────┐
llm/ (tools, observe, safety, agent, computer_use, mcp_server)      │
rpa/ (robot, queue, flow, recorder, report)                         │
desktop.py  (Desktop facade)  +  compat/pyautogui.py                 │
element.py  window.py  selectors.py  wait.py                         │
mouse.py  keyboard.py  motion.py  failsafe.py  screen.py  vision.py  ocr.py
backends/base.py (Backend, AccessibleNode)   types.py  keys.py  errors.py
backends/mock.py   backends/{windows,macos,x11}/ (packages: one module per concern, backend.py composes mixins)
```

Lower layers never import higher ones (except lazily inside a function).

## Foundation (already written — do not change signatures)

* `locum.types`: `Point(x,y)`, `Rect(left,top,width,height)` (`.center .right .bottom .contains .intersect .union .iou .offset .inflate .as_tuple .as_ltrb .to_dict`, `Rect.coerce`, `Rect.from_ltrb`), `MouseButton` (`.coerce`), `Monitor`, `WindowInfo`, `Match(rect, confidence, text="", scale=1.0, extra={})` with `.center`, `coerce_point(any)`.
* `locum.errors`: `LocumError, BackendError, BackendUnavailable, NotSupported, FailSafeTriggered, ActionTimeout, ElementNotFound, AmbiguousElement, ImageNotFound, WindowNotFound, SelectorSyntaxError, PolicyViolation, WorkflowError`.
* `locum.keys`: `KEYS, MODIFIERS, normalize_key, is_modifier, parse_hotkey, lower_combo_letters, SHIFTED_CHARS, char_needs_shift, split_text_tokens`. In a combo that contains a modifier, single letters are lowercased (`"Ctrl+S"` is ctrl+s; Shift only when named); `"\n"`/`"\r"` are enter and `"\t"` is tab (also inside combos); `"ctrl--"` is ctrl+minus; `"^"` is the caret character (`"⌃"` is the ctrl alias).
* `locum.backends.base`: `Backend`, `AccessibleNode`, `ROLES`, `CAP_*` constants. `wait_clipboard_read(since, timeout) -> Optional[bool]` (default None = cannot tell; X11 native clipboard waits for an app to fetch the text). `save_clipboard() -> Any` / `restore_clipboard(saved)` (default: the text via `get_clipboard`/`set_clipboard`; Windows: `ClipboardSnapshot` of every format that is a global memory block). `accessibility_roots()` lists roots front-most first (like `list_windows()`); the default `element_at` searches only the first root that has an element at the point (never a control hidden behind the front window). `WindowsBackend.launch` starts a bare program name not on PATH (`excel`, App Paths), a document (`Q3.xlsx`) or a URL with `ShellExecuteExW`, like Start > Run; explicit program paths, argument lists and Popen keyword options use `subprocess.Popen`.
* `locum.backends`: `get_backend, set_backend, create_backend, register_backend`.
* `locum.backends.mock`: `MockBackend` (simulated desktop with widgets, a11y tree, rendering, event log `be.events`), `MockWindow`, `MockWidget`, `MockNode`. Use it in tests: `be = MockBackend(); w = be.add_window("T", (100,100,400,300)); b = w.add_button("OK", (10,10,80,30)); e = w.add_edit("Name", (10,50,200,28))`. Widget rects are window-relative; `widget.screen_rect` is absolute. Events: `("move",x,y)`, `("down",btn,x,y)`, `("up",btn,x,y)`, `("scroll",dx,dy,x,y)`, `("key_down",k)`, `("key_up",k)`, `("type",text)`, `("screenshot",region)`, ... Keyboard focus follows the active window (activating a window restores the widget it last focused; a minimized, closed or inactive window never receives keystrokes); Alt+letter never types; `ctrl+a` selects until the caret moves, focus changes or the field is clicked; an invisible widget hides its whole subtree (a11y, rendering, hit-testing, Tab order); `MockNode.toggle()`/`focus()` return False for a disabled widget.

## Input layer

### `motion.py`
* `TWEENS: dict[str, Callable[[float], float]]` — `linear, ease_in_quad, ease_out_quad, ease_in_out_quad, ease_in_cubic, ease_out_cubic, ease_in_out_cubic, ease_out_back, ease_in_out_sine`.
* `@dataclass Humanize(speed: float = 1.0, jitter: float = 1.0, overshoot: bool = True, curvature: float = 1.0, seed: Optional[int] = None)` — `rng` property.
* `def plan_path(start: PointLike, end: PointLike, *, duration: float, tween: str|Callable = "ease_in_out_quad", humanize: Optional[Humanize] = None, rate: int = 120) -> List[Tuple[Point, float]]` — waypoints `(point, t_offset_seconds)`, last point == end exactly; humanized = randomized cubic Bézier + slight overshoot/correction + jitter, deterministic with seed.
* `def fitts_duration(distance: float, target_width: float = 20, speed: float = 1.0) -> float` — Fitts's-law natural movement time (clamped ~0.08–1.2s).

### `failsafe.py`
* `class FailSafe(backend, enabled: bool = True, corners: Optional[List[Point]] = None, margin: int = 0)` — `.check()` raises `FailSafeTriggered` if cursor in a corner (default: every outer monitor corner the cursor can actually reach, from `backend.monitors()`; the 4 virtual-screen corners if monitors are unavailable) or if `abort()` was called. `.enabled` attr.
* Module-level: `abort(reason="")` (sets global abort event), `reset_abort()`, `is_aborted() -> bool`, `abortable_sleep(seconds, sleep=time.sleep) -> bool` (returns early with True on `abort()`; used by `Desktop.sleep`, `Robot.sleep` and `WorkQueue.process` retry waits), `install_kill_hotkey(combo="ctrl+alt+shift+q") -> bool` (pynput, optional; returns False if unavailable or if the listener cannot receive events: its thread died, e.g. no X RECORD extension, or macOS without Accessibility/Input Monitoring permission; raises ValueError for combos that could never fire, e.g. shift + a non-letter character, altgr + a character, ctrl+alt+F<n> on Linux).

### `_inputlock.py` (desktop input lock)
One owner of the mouse/keyboard/focus at a time. `hold(obj, timeout=None)` (re-entrant per thread; `obj` = Desktop/Keyboard/Mouse/Element/backend), `desktop_input(desktop, timeout=None)` (public context manager), `try_desktop_input(desktop)` (yields False instead of waiting), `locked` (method decorator), `holder(obj)`, `enabled()`. Real backends (`windows`, `macos`, `x11`) share one session-wide lock across processes: a named mutex `Local\locum-desktop-input` on Windows (`WAIT_ABANDONED` after an owner died counts as acquired), `flock` on `$TMPDIR/locum-desktop-input-<uid>[-<display>].lock` on POSIX; other backends (mock) get an in-process lock per backend object unless they set `desktop_lock_name`. Taken by `Keyboard.down/press/hotkey/type/hold`, `Mouse.move/down/click/drag/scroll` and, for the whole call, every `@_bound_input` `Element` method (`set_text` only around its typing path: native set-value needs no input). Never taken by releases (`up`, `release_all`). Timeout: `Desktop(input_lock_timeout=30)` (propagated to its Mouse/Keyboard) → `DesktopBusy` naming the holder (pid/thread from a `<name>.owner` sidecar). `LOCUM_DESKTOP_LOCK=0` disables it.

### `mouse.py`
`class Mouse(backend, failsafe: Optional[FailSafe] = None, pause: float = 0.0, humanize: Optional[Humanize] = None, sleep=time.sleep)`
* `position() -> Point`
* `move(x, y=None, *, duration: Optional[float] = None, tween="ease_in_out_quad", humanize: Optional[Humanize|bool] = None) -> Point` — `x` may be any point-like (then `y` None). `duration=None` → instant unless humanize active (then Fitts). Calls `failsafe.check()` before and during moves.
* `move_rel(dx, dy, **kw)`
* `down(button="left")`, `up(button="left")`; `pressed -> List[MouseButton]` (held via `down()`), `release_all()` — releases every button this instance holds via `down()` (called by `Desktop.close()`).
* `click(x=None, y=None, *, button="left", clicks=1, interval=0.0, duration=None, humanize=None) -> Point` (x may be point-like or None = current position)
* `double_click(...)`, `triple_click(...)`, `right_click(...)`, `middle_click(...)`
* `drag(start, end, *, button="left", duration=0.5, humanize=None, hold=0.05)` (start None = current position)
* `scroll(dy=0, dx=0, *, at=None)` — notches, dy>0 = up.

### `keyboard.py`
`class Keyboard(backend, failsafe: Optional[FailSafe] = None, pause: float = 0.0, sleep=time.sleep, *, clipboard_settle: float = 0.5, clipboard_timeout: float = 2.0)`
* `down(key)`, `up(key)` (accept aliases; normalize via `keys.normalize_key`)
* `press(*keys, presses=1, interval=0.0)` — taps each key in sequence (`press("tab", "tab", "enter")`); a combo argument (`"ctrl+c"`, `["ctrl","c"]`, `"ctrl alt del"`) is a hotkey, a string of several keys without modifiers (`"tab tab enter"`) is tapped in sequence (`keys.press_actions(spec)`); ambiguous strings (`"shift tab tab"`) and combos naming a non-modifier key twice (`"tab+tab"`, also in `hotkey`/`hold`) raise `ValueError` (`keys.check_combo`).
* `hotkey(*keys)` — `hotkey("ctrl+shift+s")` or `hotkey("ctrl","c")` (letters lowercased when a modifier is present: `hotkey("Ctrl","S")` sends ctrl+s); press in order, release in reverse **in a finally** (never leave stuck modifiers).
* `hold(*keys)` — context manager.
* `type(text, *, interval=0.0, mode="auto")` — modes: `"unicode"` (backend.type_text), `"keys"` (per-char key taps: each character goes to `backend.key_down`/`key_up`, and the backend adds Shift/AltGr for the active layout and CapsLock state, `\n`→enter, `\t`→tab), `"clipboard"` (save clipboard → set → paste via `mod+v` → wait until the app read it → restore; saving/restoring uses `backend.save_clipboard()`/`restore_clipboard(saved)` — the base backend keeps the text, Windows snapshots every global-memory format (images, file lists, Excel ranges); the wait is `backend.wait_clipboard_read(since, clipboard_timeout)` where the backend can tell (X11 native clipboard; if the app has not read it in time the clipboard is not restored, so a late paste still inserts the typed text), else a fixed `clipboard_settle` sleep, also between consecutive pastes), `"auto"` (unicode if backend has CAP_UNICODE_TYPING; else keys for ASCII, clipboard for non-ASCII).
* `release_all()` — releases every key this instance pressed (a key is recorded before the backend call, so a press cut off by Ctrl+C is still released); a key whose release fails stays recorded (so a later call retries it) and the first error is raised after every key was attempted.

## Screen & vision

### `screen.py`
`class Screen(backend)`
* `capture(region: Optional[RectLike] = None, *, monitor: Optional[int] = None) -> PIL.Image` (RGB)
* `monitors() -> List[Monitor]`, `size() -> Tuple[int,int]` (primary), `virtual_rect() -> Rect`
* `pixel(x, y) -> Tuple[int,int,int]`, `pixel_matches(x, y, color, tolerance=0) -> bool`
* `wait_for_change(region=None, *, timeout=10, interval=0.2, threshold=0.01) -> bool`
* `wait_until_stable(region=None, *, stable_for=0.5, timeout=10, interval=0.1, threshold=0.001) -> bool`
* Both wait helpers (also `metric="mean"|"pixels"`, `pixel_tolerance=8`) measure the difference per 64x64 block (half-overlapping) and use the most changed block, so a localized change (spinner, message bar) on a full-screen capture is not averaged away; regions smaller than a block compare as a whole.
* `save(path, region=None) -> str`

### `vision.py` (pure functions; numpy; use cv2 only if importable)
* `load_image(src) -> PIL.Image` — path / `pathlib.Path` / PIL / numpy array / bytes / base64 str / data URL.
* `locate(needle, haystack, *, confidence=0.9, grayscale=False, scales: Sequence[float] = (1.0,), region: Optional[RectLike] = None, offset=(0,0)) -> Optional[Match]` — normalized cross-correlation (FFT); **alpha channel of the needle acts as a mask** (for a needle whose opaque pixels are one solid color — a monochrome glyph — the mask is the shape: its transparent area must mostly differ from that color, so solid areas of the glyph color do not match); result rects are in haystack coords (+offset).
* `locate_all(needle, haystack, *, confidence=0.9, grayscale=False, scales=(1.0,), limit=100, overlap=0.3, region=None, offset=(0,0)) -> List[Match]` — non-max suppression, sorted by confidence desc.
* `find_color(haystack, color, *, tolerance=0, region=None, offset=(0,0)) -> List[Rect]` — connected regions of matching pixels.
* `image_diff(a, b, *, tile=None) -> float` — 0.0 identical .. 1.0 totally different (mean abs diff normalized); `changed_fraction(a, b, *, pixel_tolerance=0, tile=None) -> float`; with `tile` both return the largest value over `tile`x`tile` blocks.
* `annotate(image, boxes: Sequence[Tuple[RectLike, str]], *, color=(255,0,0), offset=(0,0)) -> PIL.Image` — draw labeled boxes (used by set-of-marks).
* `to_base64_png(image, *, max_size: Optional[int] = None) -> str`, `downscale(image, max_long_edge) -> Tuple[PIL.Image, float]` (returns scale factor applied, ≤1).

### `ocr.py`
* `@dataclass OCRWord(text: str, rect: Rect, confidence: float, line: int = 0)`
* `class OCREngine(Protocol)`: `read(image) -> List[OCRWord]`
* `register_ocr_engine(name, factory)`, `get_ocr_engine(name: Optional[str] = None) -> OCREngine` (auto: tesseract via pytesseract → rapidocr → easyocr; raise `NotSupported` with install hint).
* `read_text(image, *, engine=None) -> str` (lines joined by `\n`)
* `find_text(image, query, *, engine=None, regex=False, case_sensitive=False, fuzzy: float = 1.0, offset=(0,0)) -> List[Match]` — matches single words or multi-word phrases on the same line (consecutive words at most ~3 character widths apart; a split word like `Log in` for `Login` is joined only across a gap of <= ~1.5 character widths and ranks after exact matches); tokens containing a digit keep their sign, parentheses and leading decimal point (`-1,500.00`, `1,500.00-`, `(250.00)` never equal `1,500.00`/`250.00`); an invalid regex raises `ValueError` before OCR runs; `fuzzy<1` uses difflib ratio.

## UI layer

### `wait.py`
* `wait_until(predicate, timeout=10.0, interval=0.1, *, message=None, backoff=1.0, max_interval=1.0, ignore_exceptions=True, sleep=time.sleep, clock=time.monotonic)` → returns the first truthy result; raises `ActionTimeout(message)`; `timeout=0` = single check. `ignore_exceptions`: `True` swallows every `Exception` (module default), `False` none, an exception type/tuple those, `"transient"` only errors `locum.errors.is_transient` accepts.
* **Transient vs. fatal (all Desktop/Element/Window waits).** Every library wait (`Desktop.find`/`window`/`wait`/`wait_until`/`locate`/`wait_image`/`find_text`, scoped `Element.find`/`Window.find`, `Element.wait_until`, `Window.wait_closed`) retries only *transient* errors: `ElementNotFound`, `WindowNotFound`, `ImageNotFound`, `AmbiguousElement`, inner `ActionTimeout`, `BackendError` (except its fatal subclasses), `OSError` (except `PermissionError`), and accessibility/capture bridge errors matched by module (`_ctypes.COMError`, `comtypes`, `Xlib`, `gi`, `pyatspi`, `dbus`, `objc`, `mss`). Everything else is *fatal* and raised unchanged on the first probe: `FailSafeTriggered`, `PolicyViolation`, `BackendUnavailable`, `NotSupported`, `PermissionDenied`/`PermissionError`, `SelectorSyntaxError` and other `ValueError`s, `TypeError`, `AttributeError`, `NameError`, `AssertionError`, `ImportError`, and any unlisted type (`RuntimeError`, `KeyError`, ...). An exception's boolean `transient` attribute (`BackendError("busy", transient=True)`) overrides the rule, except for stop requests. After the timeout the `ActionTimeout` names the last transient error. Behaviour change in 0.1.0: `Desktop.wait_until` defaults to `ignore_exceptions="transient"` (pass `ignore_exceptions=True` to retry a predicate such as `lambda: data["status"]` that raises `KeyError` while not ready).
* `retry(fn=None, *, attempts=3, delay=0.5, backoff=2.0, max_delay=30.0, exceptions=(Exception,), on_retry=None, sleep=time.sleep)` — decorator (with/without args) **and** `retry(fn, attempts=...)()`-style use via `retry_call(fn, *args, attempts=..., **kwargs)`.
* `class Deadline(timeout)` — `.remaining`, `.expired`, `.sleep(interval)`.

### `selectors.py`
Selector language (CSS-like, plus UiPath-XML and dict forms), matching `AccessibleNode` trees:
* role / `*`; `#id` → automation_id; `.cls` → class_name
* attributes `[name="OK"]`, ops: `=` exact, `!=`, `*=` contains, `^=` prefix, `$=` suffix, `~=` regex search, `%=` glob (`*`/`?` wildcards); trailing ` i` flag = case-insensitive: `[name="ok" i]`. Bare-word values allowed: `[name=OK]`.
* attribute aliases: `title`→name, `id`→automation_id, `class`/`cls`→class_name, `text`→name-or-value, `app` (process name; always case-insensitive, `=`/`!=`/`%=` compare the normalised name so `[app=excel]` ≡ `[app="EXCEL.EXE"]`, `*=`/`^=`/`$=`/`~=` also see the real file name), `pid`, `role`, `value`, `description`, `handle`; anything else → `node.attributes()`.
* pseudo-classes: `:enabled :disabled :visible :focused :checked :unchecked :mixed` (alias `:indeterminate`; a tri-state box in that state is neither `:checked` nor `:unchecked`) `:selected :editable`, `:has-text("x")` (name or value contains, case-insensitive), `:has(sel)`, `:not(sel)`, `:nth(n)` (0-based index among matches of the compound so far; negative from end), `:first`, `:last`.
* shorthand: `button "OK"` ≡ `button[name="OK"]`; a bare quoted string `"OK"` ≡ `*[text="OK"]`.
* combinators: descendant (space), child `>`, adjacent sibling `+` (`text "Name:" + edit`: the edit right after the label, same parent), general sibling `~` (`group ~ button`: any later sibling); union `,`. They compose (`window "Calc" > pane text "Name:" + edit`). Search roots have no siblings; `:has()` only takes a leading `>`. `~=` (regex) stays an attribute operator inside `[...]`.
* UiPath XML: `<wnd app='excel.exe' title='*Book1*' /><ctrl name='OK' role='push button' />` — attribute values with `*`/`?` are globs; the first `wnd`/`html`/`app` = top-level window, a later `wnd` = child window (descendant), `ctrl`= descendant; `aaname`→name, `cls`→class_name, `automationid`→automation_id, UiPath roles mapped (`push button`→button, `editable text`→edit, ...).
* dict: `{"role": "button", "name": "OK", "within": {...}}`; `key__op` suffixes (`ne`, `contains`, `regex`, ..., `i` prefix = case-insensitive); state keys (`enabled`, `checked`, `mixed`, ...) take booleans (or "true"/"false" strings, anything else is a `SelectorSyntaxError`); `{"any": [sel, ...]}` = union (must be a list).
* API: `parse(selector: str|dict|Selector) -> Selector` (cached), `Selector.find_all(roots: Sequence[AccessibleNode], *, max_depth=64, limit=None) -> List[AccessibleNode]`, `Selector.find_first(roots, max_depth=64) -> Optional[AccessibleNode]`, `Selector.matches(node) -> bool` (compound only, ignores ancestry), `str(Selector)` round-trips to the CSS form.
* `def selector_for(node: AccessibleNode, *, root: Optional[AccessibleNode] = None, roots: Optional[Sequence[AccessibleNode]] = None) -> str` — generate a robust selector for a node (prefers automation_id, then role+name, adds window ancestor and `:nth` if ambiguous); `parse(selector_for(n, roots=roots)).find_first(roots)` is `n`. The ancestor prefix starts at the ancestor that is one of `roots` (application/desktop ancestors that AT-SPI/AX put above windows are never used). Without `roots`, uniqueness is only checked inside the node's own window — pass `roots=desktop.roots()` for selectors used with `Desktop.find` (the recorder, `observe()` and the CLI do). Used by the recorder & LLM layer.
* `def tree_text(roots, *, max_depth=8, interactive_only=False, max_nodes=2000, include_bounds=True) -> str` — indented human/LLM readable dump: `button "OK" #okBtn (120,340 80x30) [focused]`.

### `element.py`
`class Element(node: AccessibleNode, desktop: "Desktop", selector: Optional[str] = None)`
* properties: `node, desktop, selector, role, name, value, automation_id, class_name, bounds (Optional[Rect]), center (Point; raises ElementNotFound if no bounds), states, is_enabled, is_visible, is_focused, is_checked`
* tree: `parent -> Optional[Element]`, `children() -> List[Element]`, `find(selector, timeout=None) -> Element` (NotSupported / SelectorSyntaxError / FailSafeTriggered / PolicyViolation propagate at once, as in `Desktop.find`; same for `Window.find`), `find_all(selector) -> List[Element]`, `exists(selector, timeout=0) -> bool`
* actions (all return `self` for chaining):
  `click(button="left", clicks=1, *, offset=(0,0), native: bool|str = "auto")` — "auto": mouse click at center if visible with bounds, else native `invoke`; `native=True` → invoke only (raise if unsupported); `native=False` → mouse only. A `disabled` element is waited for up to `default_timeout` (also by `invoke()`, `double_click`/`right_click`, the toggle/select click fallbacks and `Desktop.click`), then `ElementNotFound("... is disabled")` is raised instead of reporting a click that did nothing.
  **Every mouse action on an element** (`click`, `double_click`, `right_click`, `hover`, `scroll`, the focus click, `Desktop.click(element, interval/duration/humanize=...)`, `Desktop.move/drag/scroll` with element or selector targets) is hit-tested: an element still hidden/offscreen after `scroll_into_view`, or still covered by another element after its window was activated, raises `ElementNotFound` instead of clicking whatever is drawn there.
  `double_click()`, `right_click()`, `hover()`, `invoke()`, `focus()`,
  `set_text(text, *, native="auto", clear=True, verify=True, decimal=None)` — native `set_value`, else focus/click + `mod+a` + type (mode via desktop keyboard; text containing `\n`/`\r`/`\t` is pasted in clipboard mode, never typed as Enter/Tab — `NotSupported` without a clipboard). `verify` = `True`/`"normalized"` (case, white space/line breaks and *unambiguous* number formatting such as `1250` → `1,250.00`; a locale-ambiguous number such as `1,000` matches by value only with a known `decimal` / `Desktop.decimal_separator`), `"exact"` (character for character), `"amount"` (one decimal separator, required; `Decimal` comparison; SAP trailing minus and parentheses) or `False`. A read-back that does not match after a successful native set retypes the whole target into the cleared field (never appended twice; with `verify=False` the previous lenient number rule decides whether the native set took); the field is then read back (polled ~1 s) and `ActionTimeout` naming the expected and actual values (and, for an ambiguous number, how to resolve it) is raised when it still differs (read-only, refused or truncated input; `native=True` raises at once). Every call sets `Element.last_verification` to a `VerifyResult(status, mode, expected, actual, reason)`: `"verified"`, `"skipped"` (`verify=False`) or `"unverified"` (no readable value, a password field) — an unverified result is also reported to action listeners as kind `"verify"`, and `"exact"`/`"amount"` raise `VerificationUnavailable` (an `ActionTimeout`, never retried) instead. A disabled or `readonly` edit/spinbutton raises `ElementNotFound` up front (also `type()`),
  `type(text, **kw)`, `clear()`, `press(*keys)` — `type`/`press`/`set_text` (typing path) and `focus()` raise `ElementNotFound` without sending keys when the element is disabled or does not have keyboard focus after the focus click (focus on a descendant/ancestor counts),
  `toggle()`, `check()`, `uncheck()` (toggle until checked / neither checked nor mixed — a tri-state box may need two toggles; raise `ActionTimeout` if that state is not reached), `select()`, `expand()`, `collapse()`, `scroll_into_view()`, `scroll(dy)`,
  `screenshot() -> PIL.Image`, `wait_until(state="visible"|"enabled"|"focused"|"gone"|callable, timeout=None) -> Element`, `refresh() -> Element` (re-resolve via selector), `highlight(duration=1.0)` (optional, may no-op), `to_dict() -> dict`, `__repr__`.

### `window.py`
`class Window(info: WindowInfo, desktop: "Desktop")`
* properties: `info, handle, title, rect, app, pid, is_active, is_minimized, is_maximized`
* `activate()`, `minimize()`, `maximize()`, `restore()`, `close()`, `move(x, y)`, `resize(w, h)`, `set_rect(rect)` (all return self), `refresh() -> Window`, `screenshot()`, `element -> Element` (the window's a11y root: accessibility root whose `handle` == window handle, else whose name == title), `find(selector, timeout=None) -> Element`, `find_all(selector) -> List[Element]`, `wait_closed(timeout=10)`, `to_dict()`.
* `def match_window(info: WindowInfo, title=None, app=None, class_name=None, pid=None) -> bool` — title: exact string match first, else if str contains glob chars → glob, `re.Pattern` → regex search; plain str also matches as case-insensitive substring. app: case-insensitive, `.exe` optional.

## Facade: `desktop.py` — `class Desktop`

```python
Desktop(backend: Backend|str|None = None, *, failsafe: bool = True, pause: float = 0.0,
        humanize: bool|Humanize = False, default_timeout: float = 10.0, typing_mode: str = "auto",
        sleep=time.sleep, clock=time.monotonic, poll_interval: float = 0.1,
        clipboard_settle: float = 0.5, clipboard_timeout: float = 2.0)
```
`clipboard_settle`/`clipboard_timeout` are passed to `Keyboard` (clipboard-mode typing).
Attributes: `backend, mouse (Mouse), keyboard (Keyboard), screen (Screen), failsafe (FailSafe), default_timeout, humanize (Optional[Humanize])`.

Mouse: `position()`, `move(target, y=None, *, duration=None, humanize=None, offset=(0,0), allow_offscreen=False)`, `click(target=None, y=None, *, button="left", clicks=1, interval=0.0, offset=(0,0), duration=None, allow_offscreen=False)`, `double_click`, `right_click`, `middle_click`, `triple_click`, `mouse_down(button)`, `mouse_up(button)`, `drag(start, end, *, duration=0.5, button="left", allow_offscreen=False)`, `scroll(dy=0, dx=0, *, at=None, allow_offscreen=False)`. A destination point on no monitor raises `ValueError` (naming the monitor layout) instead of being clamped to the screen edge by the OS, unless `allow_offscreen=True` (the low-level `Mouse` and the PyAutoGUI shim keep PyAutoGUI's clamping).
`target` resolution (shared helper `Desktop.resolve_point(target, y=None) -> Point`): `None` → current pos; point-like / Rect / Match / Element → coerce; `str` → treated as a **selector** (find element, use its center); `pathlib.Path` or `PIL.Image` → template locate on screen (raise ImageNotFound).

Screen/vision: `screenshot(region=None, *, monitor=None, path=None) -> Image`, `monitors()`, `size()`, `pixel(x, y)`, `locate(image, *, region=None, confidence=0.9, grayscale=False, scales=(1.0,), timeout=0.0) -> Optional[Match]` (None = not found; if the last screen capture failed, e.g. locked workstation, that error is raised instead, also from `wait_image`/`click_image`), `locate_all(image, **kw) -> List[Match]`, `wait_image(image, *, timeout=None, **kw) -> Match` (raises ImageNotFound), `click_image(image, *, timeout=None, button="left", clicks=1, **kw) -> Match`, `find_text(text, *, region=None, timeout=0.0, **kw) -> Optional[Match]`, `click_text(text, *, timeout=None, **kw) -> Match`, `read_text(region=None) -> str`, `wait_for_change(...)`, `wait_until_stable(...)`.

Elements: `find(selector, *, timeout=None, root: Optional[Element|Window] = None) -> Element` (raises ElementNotFound after timeout, naming the selector as written plus "did you mean" hints — a leading bare word that is no role, `find("Save")`, is also matched against element names with a hint to quote it; `timeout=None` → `default_timeout`), `find_all(selector, *, root=None) -> List[Element]`, `exists(selector, *, timeout=0.0) -> bool`, `wait(selector, *, state="visible", timeout=None) -> Optional[Element]` (state `"gone"` returns None); `exists`/`wait` also take a template image (existing image file, Path, bytes, PIL/numpy, data URL): `exists` locates it, `wait` returns its `Match` for `visible`/`exists` and polls until it is off screen for `gone`; `find`/`find_all` raise `TypeError` for an image, and a string ending in an image extension whose file is missing raises `FileNotFoundError` in all four, `element_at(x, y) -> Optional[Element]`, `focused() -> Optional[Element]`, `tree(*, window=None, max_depth=8, interactive_only=False) -> str`, `roots() -> List[AccessibleNode]`.

Clipboard: `clipboard_get() -> str`, `clipboard_set(text)`. Misc: `sleep(s)` (raises `FailSafeTriggered` within ~0.1 s of an `abort()`/kill hotkey, also mid-sleep; with an injected sleep function it sleeps in ≤0.1 s slices), `wait_until(predicate, timeout=None, interval=0.1)`, `close()` (releases keys and mouse buttons this desktop holds, then `backend.release_all()` when the backend has it), context manager (`with Desktop() as d:`).

## RPA layer: `rpa/`
* `rpa/robot.py`: `Robot(desktop=None, name="robot", run_dir="locum_runs", screenshot_on_error=True, logger=None)`; `@robot.task(name=None, retries=0, retry_delay=1.0, timeout=None, continue_on_error=False)`; `with robot.step("name"):` (single attempt; `retries>0` with a plain `with` raises `TypeError`), retried steps as `for attempt in robot.step("name", retries=n, retry_delay=1.0): with attempt: ...` or `robot.step("name", retries=n).run(fn, *args)`; `robot.run(*task_names) -> RunReport` (teardown hooks and report saving run whatever escapes a task; steps used outside a run start an implicit run that the next `run()` adopts); per-step timing, error capture with screenshot; `robot.log(msg)`; `robot.vars` dict. A task `timeout` is checked cooperatively (step start/end, attempt start, `robot.sleep`, task return); its `ActionTimeout` is never retried (not by the task, not by retried steps) and never swallowed by a step's `continue_on_error`. A step left unfinished is recorded failed, never passed. Setup/teardown hook signatures are checked at registration.
* `rpa/report.py`: `StepResult`, `RunReport` (`.ok`, `.steps`, `.to_dict()`, `.save_json(path)`, `.save_html(path)`).
* `rpa/queue.py`: `WorkQueue` (UiPath-Orchestrator-style transaction queue): add items (dict payloads), load from CSV/JSON/XLSX (openpyxl optional), `process(handler, *, retries=1)` with per-item status `new/in_progress/success/failed/business_exception`, `BusinessException` (no retry), persistence to JSON file so runs resume. Several threads/processes on one machine may share the file (local filesystem only; not network shares or several machines; a path in a OneDrive/Dropbox/Google Drive/iCloud/Box folder or on a UNC path or mapped network drive is refused with `ValueError` by `synced_location()` unless `allow_synced=True`; `default_queue_dir()` = `%LOCALAPPDATA%\locum\queues` / `$XDG_STATE_HOME/locum/queues`; `export(path)` writes an atomic JSON copy (re-read first, no lock sidecar) for a synced archive): every mutation takes an exclusive OS lock on `<path>.lock` (`msvcrt.locking` / `fcntl.flock`), re-reads the file when its `generation` counter changed, and writes temp + `fsync` + `os.replace` (+ directory fsync on POSIX). A claim (`next()`) records `worker_id` and a lease (`lease_duration`, default 30 min, renewed by `process()` every third of it; `renew()`/`release()` for manual use); an `in_progress` item is abandoned only when its lease expired, it has no lease (older files), or its worker process on this host is gone, and is then marked failed (`Abandoned`) unless `on_abandoned="requeue"`; a worker whose lease was reclaimed gets `LeaseLostError` instead of overwriting the new owner; attempts are persisted and enforced across runs; file rows without `reference_field` get content-hash references (`<abs path>#<sha256[:16]>`); with `reference_field` (also `add_many`), a blank key, or one key on two different rows of one load, raises `ValueError` before anything is added (identical duplicate rows dedupe). `load_csv(..., strict=True)` raises `ValueError` naming the line for a row whose field count differs from the header (an unquoted `1,250.00`), before anything is added; `strict=False` drops extra/blanks missing fields. An interrupt (Ctrl+C, `FailSafeTriggered`) while the handler runs follows `on_abandoned` (default: `failed`, error type `Interrupted`, since the side effect may have happened; `requeue`: back to `new`, attempt counts); an interrupt during a retry wait returns the item to `new`; a robot task deadline inside a handler fails the current item and stops processing.
* `rpa/flow.py`: declarative YAML/JSON workflows: `run_flow(path_or_dict, desktop=None, variables=None) -> RunReport`. Steps: `click, double_click, right_click, type, press, hotkey, set_text, invoke, toggle, select, expand, collapse, check, uncheck, wait, wait_gone, wait_image, click_image, click_text, screenshot, launch, activate_window, sleep, assert_exists, set_var, read_value, clipboard_set, log, if_exists {then, else}, for_each {items|csv, as, steps}, try {steps, catch}, call (sub-flow), repeat {times, steps}`. `${var}` interpolation (incl. `${item.field}`, `${env.NAME}`; a flow variable named `env` wins, a bare `${env}` never expands to the environment). `settings.retries`/`retry_delay` apply to action steps only (control steps never re-run their block unless they set `retries` themselves); `continue_on_error` on a control step also handles its nested failures; `settings.screenshot_on_error` is honoured. YAML scalars keep their source text (`00123`, `1250.50`; only `true`/`false` are booleans); CSV rows whose field count differs from the header are errors unless `for_each.strict: false`. A string `target` ending in an image extension (or a `data:image/` URL) is a template image in every step (`click`/`move`/`wait`/`wait_gone`/`assert_exists`/`if_exists`), resolved against the flow's directory; a missing file raises `FileNotFoundError`.
* `rpa/recorder.py`: `Recorder(desktop=None)` — `.start()`, `.stop() -> List[RecordedAction]`, uses pynput if available; enriches clicks with `selectors.selector_for(backend.element_at(x,y))` (UiPath-style selector recording, not raw coords); `.to_python() -> str`, `.to_flow() -> dict` (YAML-ready). Also `Recorder.feed(event)` for programmatic/test use without pynput. pynput callbacks only queue events (selector capture runs on a worker thread, never in the OS input hook); characters pynput reports are recorded as the layout produced them (no US shift re-mapping, AltGr is not a Ctrl chord, numpad virtual keys are translated); clipboard-mode typing on the `backend` source is recorded as `type`. Text typed or set into a password field is never stored: the action has `secret=True`, the flow step uses `${env.LOCUM_PASSWORD}` and the script `os.environ['LOCUM_PASSWORD']` (`PASSWORD_ENV`).

## LLM layer: `llm/`
* `llm/observe.py`: `@dataclass ObservedElement(id: int, role, name, value, bounds: Rect, states, selector: str, node)`; `@dataclass Observation(screenshot: Optional[Image], elements: List[ObservedElement], windows: List[WindowInfo], active_window, cursor: Point, screen_size, scale: float, annotated: Optional[Image])` with `.text(max_elements=300) -> str`, `.element(id) -> ObservedElement`, `.to_screen(x, y) -> Point` (map LLM image coords → screen using `scale`), `.to_image(x, y)`, `.image_base64(annotated=True) -> str`. `observe(desktop, *, screenshot=True, annotate=True, max_long_edge=1568, interactive_only=True, window=None, max_elements=300) -> Observation` — set-of-marks: numbered boxes on the screenshot matching element ids.
* `llm/safety.py`: `Policy(allow_tools=None, deny_tools=(), allowed_apps=None, blocked_apps=(), deny_text_patterns=(), confirm_patterns=DEFAULT_CONFIRM (e.g. delete|remove|pay|transfer|wire|submit|send|purchase|approve|post|release, plural/inflected forms, German SAP labels buchen|zahlen|überweisen|freigeben|löschen|senden), confirm: Optional[Callable[[str, dict], bool]] = None, dry_run=False, max_actions=None, max_actions_per_minute=None, region: Optional[Rect]=None, *, unknown_target="confirm"|"block"|"allow", confirm_keys=DEFAULT_CONFIRM_KEYS)`; `confirm_keys` (default `("ctrl+enter", "cmd+enter", "ctrl+s", "cmd+s")`, `mod` = both; `permissive()` clears it): a combo in `context["keys"]` (whitespace-separated combos, set by the keyboard tools on their first check, not on focus re-checks) equal to one of them always needs confirmation; keyboard shortcuts with Alt/Ctrl/Cmd or an F-key are also judged by the labels of the controls they press in the focused window (`context["shortcut_targets"]`: a node whose `access_key`/`accelerator_key` attribute equals the combo, or whose name carries the `&` mnemonic for `alt+<letter>` — `alt+p` on "&Pay now"), in the toolkit (`hotkey`, `press_keys`, which also splits `"tab tab"` items into taps) and the computer-use `key` action; other application shortcuts (F8 = Execute in SAP) are not gated unless listed in `confirm_keys`; `unknown_target`: activating input (left click, Enter/Space, typed text) whose target cannot be identified (unreadable focus, nothing hit-tested under the pointer; tools set `context["target_unknown"]`) needs confirmation / is refused / runs (ignored without `confirm_patterns`); `context["arg_texts"]` (strings matched against `confirm_patterns`) and `context["require_confirmation"]` (always ask) are used for agent extra tools; `Policy.check(tool_name, args, *, context: dict, count: bool = True) -> None` raises PolicyViolation (`count=False`: re-check a later step of an already-checked action, e.g. the Enter after a Tab once focus moved — every rule but budget/rate limit, nothing counted); `AuditLog(path=None)` JSONL `record(event: dict)` (toolkit: a failed audit write appends an `AUDIT LOG WRITE FAILED` note to the result, never turns it into an error); `allowed_apps`/`blocked_apps` judge the target's app(s) (element, focused control, app under the pointer; the active app only when no target is known), and `launch_app` checks the program `launch_program(command)` (quote-aware first token; `open -a NAME` -> NAME; an unquoted multi-word command without `/` is judged as a whole app name too, e.g. `Google Chrome`, which the macOS backend opens with `open -a`) against both; `deny_text_patterns` items are regexes or matchers with `.search`/`.pattern` (`CARD_NUMBER`: Luhn-valid card numbers, IBANs ignored, `match_window_title = False`); keyboard actions with Enter in a single-line field are also judged by the label of the form's default button (`"default"` state), in both the toolkit and the computer-use adapter; toolkit element targets of activating actions (click, type_text/set_value, which may click to focus) are also judged by the label of the descendant the mouse would hit at the element's click point (a group whose centre is a "Pay now" button); text typed into a password field (`_nodeinfo.is_password`: `password`/`protected` state, AT-SPI `password text`, macOS `AXSecureTextField`) is replaced by `***` in audit args, descriptions and results; `Policy.permissive()`, `Policy.strict()` presets.
* `llm/tools.py`: `@dataclass ToolResult(text: str = "", image_base64: Optional[str] = None, is_error: bool = False, data: Any = None)`; `ToolSpec(name, description, parameters: dict JSON schema, fn, read_only=False, confirm=False)` (`confirm=True`: every call of an agent extra tool needs human confirmation); `ToolRegistry` with `.register(fn=None, *, name=None, description=None)` decorator (schema from type hints + docstring Args section), `.call(name, args) -> ToolResult` (never raises; errors → is_error), `.to_anthropic() -> List[dict]` (`name, description, input_schema`), `.to_openai()`, `.to_mcp()` (`name, description, inputSchema`), `.names()`. `DesktopToolkit(desktop, policy=None, audit=None, observe_kwargs=None)` builds a registry with tools: `observe, screenshot, click (element_id | x,y | selector | text), double_click, right_click, type_text (optional element_id/selector first), press_keys, hotkey, scroll, move_mouse, drag, set_value, find_elements, wait_for, list_windows, focus_window, launch_app, read_clipboard, write_clipboard, read_text (OCR), wait (seconds)`. Element ids refer to the last observation; coordinates in tool args are **screen coordinates of the last observation's image space** (converted via `Observation.to_screen`). Every call goes through `policy.check` and `audit.record`.
* `llm/computer_use.py`: `ComputerUseAdapter(desktop, *, max_long_edge=1568|auto, policy=None)` executes Anthropic computer-use actions: toolset members (`screenshot, zoom, left_click, right_click, middle_click, double_click, triple_click, left_click_drag, mouse_move, left_mouse_down, left_mouse_up, cursor_position, scroll, type, key, hold_key, wait`) with params `coordinate, start_coordinate, text (modifiers for clicks/scroll; key combo for key/hold_key; xdotool-style names like Return, ctrl+s, alt+Tab, super), scroll_direction, scroll_amount, repeat, duration, region` and legacy `input.action` form. `.tool_definition()` → `{"type": "computer_toolset_20260801"}` (+ optional configs), `.execute(name, input) -> ToolResult`, `.run_batch(tool_use_blocks) -> List[dict tool_result]` (sequential, stop at first failure, `"Not executed: an earlier computer action in this turn failed."`, every result includes `"toolset_name": "computer"`). `.release_all() -> List[str]` releases buttons pressed by `left_mouse_down` and not released since (never blocked by the fail-safe). Screenshots downscaled so long edge ≤ 2576 and ceil(w/28)*ceil(h/28) ≤ 4784; coordinates scaled back.
* `llm/agent.py`: `Agent(desktop=None, *, model="claude-opus-5-5", client=None, mode="tools"|"computer_use", policy=None, audit=None, max_steps=50, system_prompt=None, on_step=None, effort="high")`; `.run(task: str) -> AgentResult(success, final_text, steps: List[AgentStep], usage)`. ## Testing conventions
* `pytest`, tests in `tests/test_<module>.py`. Use `MockBackend` everywhere; never require a display except tests marked `@pytest.mark.x11` which must `pytest.skip` when `$DISPLAY` / Xvfb is unavailable.
* Inject `sleep=lambda s: None` / tiny durations to keep tests fast (< 2s per file).
* Run: `cd /home/user/locum && python -m pytest -q tests/test_<module>.py`.
